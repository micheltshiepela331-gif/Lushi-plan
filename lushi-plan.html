Aide — Lushi Plan

Les doigts

  • Un doigt : pose un point. Glisse pour viser, le point se pose quand tu lèves le doigt.
  • Deux doigts : écarter ou pincer pour zoomer, glisser pour déplacer la vue.
  • Sélection : touche un objet. Glisse pour tracer un cadre (vers la droite : objets entièrement dedans ; vers la gauche : objets touchés).
  • Les carrés bleus d'un objet sélectionné se tirent pour le modifier.

Longueurs exactes

  • Après le premier point, tape la longueur en bas (ex : 3.55), puis appuie sur une flèche → ↑ ← ↓.
  • Point exact : 2;3 (X;Y). Décalage : @4;3. Longueur et angle : @3.55<90.
  • Les longueurs se tapent dans l'unité choisie (onglet Gérer) : mètres, centimètres ou millimètres.

Les onglets

  • Début : dessin, murs, portes, fenêtres, escaliers, modifications, calques.
  • Insérer : meubles et équipements (lit, WC, douche, voiture…), photo d'un plan à recopier.
  • Annoter : textes, cotes, cotes de rayon, repères, surfaces.
  • Paramétrique : rendre horizontal, vertical, imposer une longueur, rendre égal ou perpendiculaire.
  • Vue : zoom, grille, fond clair pour dessiner au soleil, plein écran.
  • Gérer : unités et réglages. Sortie : PDF, image, DXF.
  • Modules d'extension : métré du bâtiment (murs, blocs, briques).
  • Collaborer : partager le plan par WhatsApp. Express Tools : compter, sélectionner en groupe.

Commandes à taper

Précision

  • Les points sont gardés au millième de millimètre. Onglet Gérer › Réglages : choisis l'affichage (cm, mm, 0,1 mm) et le pas de l'aimant.
  • Sélectionne un objet : tu peux taper ses coordonnées exactes, sa longueur et son angle.
  • Outil Point (Annoter) : lit les coordonnées exactes d'un point.

Nouveautés

  • Accrochage intersection, perpendiculaire, tangente.
  • Étirer (cadre puis base et destination), Couper, Joindre, Décomposer.
  • Mes blocs : sélectionne des objets, Créer, donne un nom et un point de base.
  • Texte sur plusieurs lignes : tape le signe | pour aller à la ligne.
  • Onglets en haut : plusieurs plans ouverts. PDF en traits : un vrai PDF net à toute taille.
  • 3D : étages, toits à 2 ou 4 pans, matériaux, boîte, cylindre, extruder. Métré : coûts en $ ou en FC.

Paramétrique

  • Sélectionne un ou deux objets, puis choisis la contrainte. Elle reste attachée : si tu modifies le dessin, la contrainte est respectée.
  • Fixe bloque un objet. Auto ajoute horizontal, vertical et coïncident tout seul.
  • Le Gestionnaire liste toutes les contraintes : change une valeur ou supprime-la.

Vue

  • Zoom fenêtre : trace un cadre. Zoom préc. revient en arrière. Vues nommées : garde un cadrage pour le retrouver.
  • SCU › Origine : choisis un point qui devient 0;0 pour les coordonnées.
  • Vues 3D et Styles visuels (réaliste, conceptuel, filaire, rayons X).

3D et 4D

  • 3D (onglet Vue, ou bouton 3D à droite) : les murs montent en volume avec portes, fenêtres, escaliers, toit et meubles. Un doigt pour tourner, deux doigts pour zoomer.
  • 4D : le chantier avance jour après jour. Règle la date de début et les durées dans « Planning ».
  • Hauteurs des murs, portes, fenêtres et allèges : onglet Gérer › Réglages.

Fichiers

  • .lplan : le fichier de Lushi Plan, à rouvrir plus tard.
  • DXF : s'ouvre dans AutoCAD. Lushi Plan ouvre aussi les DXF simples. Les DWG s'ouvrent aussi : il faut internet la première fois pour charger le lecteur.
  • Le dessin est aussi gardé automatiquement dans le téléphone.
